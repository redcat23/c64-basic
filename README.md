# C64 BASIC

Commodore 64 BASIC projects, experiments, and documented learning.

This collection focuses on understanding how the programs work, developing them incrementally, and balancing responsiveness with readable code.

## Projects

### Tetris

A work-in-progress Tetris-style game written in Commodore BASIC V2.

Currently implemented:

- Seven pieces with movement and rotation
- Collision detection against borders and settled blocks
- Hard drop and delayed locking
- Automatic falling with an adjustable interval
- Keyboard lookup table with held-key movement

Planned:

- Completed-line detection and clearing
- Scoring and ten-level progression
- Next-piece preview
- Game-over detection

Additional C64 BASIC projects will be added as they are reviewed and documented.

## Development tools

The Tetris project is developed with CBM prg Studio and tested using the VICE C64 emulator. Individual project folders will contain their own build instructions and notes.

## Contributions

Questions, bug reports, and focused improvements are welcome.

For bug reports, describe what happened, what you expected, and the steps needed to reproduce it. Include the emulator or hardware used.

For code changes, explain the change and how it was tested. Readability and game responsiveness both matter.
